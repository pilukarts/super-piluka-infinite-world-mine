# Super Piluka: Infinite World Mine

Juego de exploración, minería y fantasía para Telegram.

## Idea

Super Piluka explora una mina infinita llena de rocas, estrellas, plantas mágicas, mineros aliados, mineros rivales, fantasmas y prisioneros.

El objetivo es llegar a **The Infinite Core**, donde se encuentra el Pilukium: un recurso mágico que el mundo necesita.

## Tecnologías previstas

- Telegram Bot
- Telegram Mini App
- JavaScript o TypeScript
- Backend con API
- Base de datos para usuarios, inventario y progreso
- Telegram Stars para compras digitales

## Monedas del juego

- Estrellas
- Pilukium
- Piluka Sats (moneda interna ficticia)

## Primera versión

- Tablero de mina 8x8
- Movimiento por casillas
- Romper rocas
- Encontrar estrellas
- Fantasmas y mineros
- Guardado de progreso
- Tienda con Telegram Stars
